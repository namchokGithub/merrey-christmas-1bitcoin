# Christmas Wish 🎄

การ์ดคริสต์มาสแบบหน้าเดียวสำหรับส่งคำอวยพรให้เพื่อน พร้อมแอนิเมชันและมุกแจ้งเตือนหลอกเล่น ทุกอย่างอยู่ในไฟล์ HTML เดียว

## เริ่มใช้งาน

เปิดไฟล์ `merrey_christmas-1bitcoin.html` ด้วยเบราว์เซอร์ หรือส่งไฟล์นี้ให้เพื่อนเปิดได้โดยตรง ไม่ต้องติดตั้งโปรแกรมหรือเปิดเซิร์ฟเวอร์

ฟอนต์จาก Google Fonts ต้องใช้อินเทอร์เน็ต หากโหลดไม่ได้ การ์ดจะใช้ฟอนต์สำรองที่กำหนดไว้แทน

## ภายในการ์ด

- สลับภาษาไทยและอังกฤษได้จากปุ่มมุมขวาล่าง โดยเริ่มต้นเป็นภาษาไทย
- มีหิมะ แสงออโรรา ซานต้ากับกวาง และดาวตกเมื่อคลิกหรือแตะหน้าจอ
- เปิดคำอวยพรเพื่อพบกับหน้าต่างแจ้งเตือนมุกสุ่ม แล้วกดเฉลยหรือเลือก **มีอะไรอีก** เพื่อสุ่มมุกถัดไป
- รองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์

## ปรับแต่ง

แก้ไฟล์ `merrey_christmas-1bitcoin.html` ด้วยโปรแกรมแก้ไขข้อความ:

- คำอวยพรและข้อความส่วนต่าง ๆ ของการ์ดอยู่ในตัวแปร `translations` โดยแยกเป็น `th` และ `en`
- ข้อความแจ้งเตือนอยู่ในฟังก์ชัน `renderPrank()` และการสุ่มอยู่ใน `choosePrank()`
- สี รูปทรง และแอนิเมชันอยู่ในส่วน `<style>` ภายในไฟล์เดียวกัน

## เผยแพร่บน GitHub Pages

เมื่อพร้อมเผยแพร่ ให้นำไฟล์ขึ้น repository แล้วเปิด GitHub Pages จากการตั้งค่าของ repository โดยเลือก branch และโฟลเดอร์ที่เก็บไฟล์ หากต้องการให้เปิดการ์ดจาก URL หลักของเว็บไซต์ ให้ตั้งชื่อไฟล์ที่เผยแพร่เป็น `index.html` หรือระบุชื่อไฟล์ HTML ต่อท้าย URL

โปรเจกต์นี้ยังไม่ได้ตั้งค่าหรือเผยแพร่ GitHub Pages
